# jwks-verify-kit

**驗外部 IdP 的非對稱 JWT（ES256/384/512）+ JWKS 公鑰快取，零依賴 fail-closed** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/jwks-verify-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('jwks-verify-kit');
const x = create({ /* opts */ });
```
